# Write a SYMPTOM/CAUSE/FIX row for anything that cost a debugging cycle

In the same PR as the fix, add a row to `docs/ci-troubleshooting.md` stating the symptom someone would search for, the measured cause and the fix. Add a line to `AGENTS.md` when the lesson generalises. A row that only says what changed is a changelog entry, not a troubleshooting entry.

Source: `AGENTS.md` PR contract rule 6.
