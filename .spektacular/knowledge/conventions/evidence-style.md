# State the constraint and the measured evidence, not the story

In comments, docs, commit messages and PR bodies, state the constraint and the run/log/command output that proves it. Paste passing output for what you claim to fix, and one line of evidence (curl, resolved URL, run link) for any external claim such as a pin or transport change.

Source: `AGENTS.md` PR contract rules 1-2 and "Evidence style".
