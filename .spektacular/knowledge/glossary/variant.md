# variant

A base-distro line of TunaOS images, named after a fish; the id is the image name (`ghcr.io/tuna-os/<variant>`). Defined in `.github/build-config.yml` `variants[]`:
yellowfin = AlmaLinux Kitten 10; albacore = AlmaLinux 10; skipjack = CentOS Stream 10; wahoo = Fedora ELN (EL11 preview); bonito = Fedora 44; bonito-rawhide = Fedora Rawhide; hummingbird = Project Hummingbird (hardened Rawhide fork, no desktop by design; see `docs/HUMMINGBIRD.md`); sailfin = openSUSE Tumbleweed; guppy = Gentoo; gurnard = Ubuntu 24.04 + Pantheon; grouper = Ubuntu 26.04; marlin = Arch (CachyOS kernel overlay); flounder = Debian 13; flounder-sid = Debian Sid.
