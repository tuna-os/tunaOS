# ADR 0004: RFC lifecycle (RFC-PROCESS.md)

Accepted. Draft -> Review -> Merged -> ADR (or Abandoned). An `rfcNNN-*` branch merges only with `docs/rfc/rfcNNN-title.md`, a tracking issue, maintainer sign-off and an ADR; stale after 30 days. Small contained changes need no RFC. `docs/adr/0004-rfc-lifecycle.md`, `RFC-PROCESS.md`.
