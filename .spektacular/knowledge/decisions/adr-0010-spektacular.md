# ADR 0010: Spec-driven work with Spektacular

Accepted. Use Spektacular for an RFC (required) and for a change that touches more than one area or ports work between branches (recommended); small fixes skip it. Commit `.spektacular/` and the `spek-*` skills; pin the version as `spektacular` in `image-versions.yaml`. `docs/adr/0010-spec-driven-work-with-spektacular.md`, RFC 011.
