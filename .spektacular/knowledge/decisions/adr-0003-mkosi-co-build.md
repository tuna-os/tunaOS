# ADR 0003: mkosi co-build POC (proposed)

Proposed, not built. Prototype one variant (`bonito:gnome`) as both bootc OCI and a plain DDI from one `mkosi/` tree with two profiles, before any wider move off Containerfiles. The sysupdate/verity DDI model is out of scope. `docs/adr/0003-mkosi-co-build-poc.md`.
