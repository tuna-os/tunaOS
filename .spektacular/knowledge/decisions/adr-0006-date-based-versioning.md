# ADR 0006: date-based tags with stability tiers, not SemVer

Accepted. Daily `<variant>-<YYYYMMDD>`, weekly `<variant>-weekly-<YYYYWW>`, LTS `<variant>-lts-<quarter>`. SemVer rejected: no upstream cadence to hang major/minor on across several continuously rebuilt bases. `docs/adr/0006-date-based-versioning.md`, `VERSIONING.md`.
