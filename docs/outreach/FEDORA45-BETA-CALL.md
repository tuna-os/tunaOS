# Fedora 45 beta call — superseded draft

The [release-window outreach plan](../FEDORA45-RELEASE-OUTREACH.md) replaces
this draft for [#3089](https://github.com/tuna-os/tunaos/issues/3089).
Use its reviewed Show-and-tell copy, candidate evidence requirements, and
publication notes for the release window.

The draft previously equated Rawhide with Fedora 45. It also presented
changes to host packages as persistent additions to a deployment. Do not publish or run that draft.
`tunaos.toml` selects the Fedora 44 base for Bonito and a separate
Rawhide base. These choices do not establish support for Fedora 45.

Follow [FEDORA-BASE-POLICY.md](../../FEDORA-BASE-POLICY.md) for base transitions
and [FEDORA-OUTREACH-READINESS.md](../FEDORA-OUTREACH-READINESS.md) for the
candidate checks. The [earlier call for tests](../FEDORA45-TESTING-CALL.md) is
historical preparation for
[#1742](https://github.com/tuna-os/tunaos/issues/1742); recheck its dated
claims and trial instructions before reuse. Release-window coverage does not
promote a variant or prove that a candidate works.
