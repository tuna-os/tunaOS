# Community Engagement Plan: Linux Gaming on Container-Native TunaOS

## Overview

This community engagement plan outlines outreach strategies for Linux gaming communities, handheld Linux enthusiasts, and Steam Deck users interested in container-native immutable operating systems (Skipjack KDE, Marlin Arch, Bonito Fedora).

## Value Proposition for Gamers

- **Atomic Image Updates**: Zero risk of partial package upgrades breaking graphics drivers or Steam dependencies.
- **Flatpak First Application Delivery**: Isolated runtime environment for Steam, Heroic Games Launcher, and Lutris via Flathub.
- **Resilient Fallback**: Automatic rollback capability via bootc and ostree state handling if a driver update exhibits regressions.

## Targeted Communities

1. **r/linuxgaming & Lemmy !linuxgaming**: Showcase immutable desktop gaming stability and container-native workflows.
2. **CachyOS / Arch Linux Gaming Communities**: Solicit feedback on Marlin (Arch-based) variant performance and kernel optimization.
3. **Steam Deck / Handheld Enthusiasts**: Explore container-native base images for handheld and htpc gaming form factors.

## Engagement Workflow

- Share user guides for setting up Steam, MangoHud, and proprietary GPU drivers on TunaOS.
- Collect structured feedback on Flatpak game performance and hardware controller support.
- Direct community feedback to the TunaOS GitHub issue tracker and Matrix discussion room `#tunaos:reilly.asia`.
