## Add or update a credit

After a human contribution merges, invite the author to add a linked credit
here. Use their public handle by default. Add a full name or other details
only when the contributor supplies them for this page. A contributor can
request a correction or removal through an issue or PR.

Verify the merged PR and human authorship before adding an entry. Keep
automated contributions distinct in metrics and public thanks. Use the
[monthly highlight process](docs/CONTRIBUTOR-ROADMAP.md#recognition-and-retention)
before you publish a profile. See [the maintainer list](MAINTAINERS.md) for
current project responsibilities.
