# package-miss-allowlist.txt — packages that MAY legitimately be absent.
#
# checks/verify-package-wishlist.sh fails any build whose wishlist
# (/usr/share/tunaos/missing-on-<image>.txt, written by install_available /
# apt_install_available) contains a package NOT listed here. Listing a name
# here is a reviewed declaration: "this is a nice-to-have; an image without
# it is still correct". Anything load-bearing must instead be installed
# strictly or asserted by a verify-* contract — a DM, a greeter, a portal,
# a session package do not belong in this file even if they appear in an
# install_available probe, because their absence is caught by
# verify-desktop-experience.sh, not tolerated by this list.
#
# Deliberately NO test forces this file to mirror the install_available
# call sites. That sync is the point of the gate: adding a package to a
# best-effort list does NOT automatically make it optional — the build goes
# red until the author either packages it or adds it here, on purpose, in
# the same reviewed PR.
#
# Seeded 2026-08-07 from every best-effort request then in tree. Entries
# whose packages have since been packaged for EL10 can and should be
# removed — the gate only fires on actual misses, so deletion is safe the
# moment the package resolves everywhere.
#
# Format: one package name per line; blank lines and # comments ignored.

#    (tunaOS#1810) — the RPM Fusion Rawhide multimedia transaction, tolerant
#    ONLY when FEDORA_VER=rawhide (see build_scripts/lib.sh). ffmpeg is the
#    one that actually drops: rpmfusion-free-rawhide's ffmpeg-libs-8.1.2-5
#    Requires: liboapv.so.2()(64bit), which nothing in the enabled repos
#    provides — Fedora rawhide's openapv-libs moved to liboapv.so.3.

#    serious break and should NOT be silently allowlisted alongside this
#    one. Remove this entry once rpmfusion-free-rawhide rebuilds ffmpeg
#    against openapv 0.3 (liboapv.so.3), restoring ffmpeg on bonito-rawhide.
